SOS Aman | نظام مراقبة الغواصين

Smart Diver Protection System

نظام أمان ذكي قابل للارتداء، مصمم لمراقبة سلامة الغواص بشكل مستمر أثناء الغوص باستخدام ESP32 وحساسات لقياس العمق والحركة، مع نظام إنذار وواجهة مراقبة عبر الويب. ‎⁨التقرير النهائي للدعم والشبكات⁩.pdf

1. Project Overview

يهدف المشروع إلى تعزيز سلامة الغواصين من خلال:

• قياس عمق الغواص.
• مراقبة ميل وحركة الجسم.
• متابعة مستوى البطارية.
• إطلاق إنذار عند حدوث حالة خطر.
• توفير واجهة Web لعرض البيانات بشكل مباشر.
• توفير زر/حساس للطوارئ SOS. 

2. Technologies

• ESP32
• C++
• Arduino IDE
• MS5837 Depth Sensor
• MPU6050 Motion Sensor
• Touch Sensor
• Buzzer
• Wi-Fi
• Web Dashboard ‎⁨التقرير النهائي للدعم والشبكات⁩.pdf

3. Key Features

• 🌊 Depth Monitoring
• 📐 Tilt Monitoring
• 🔋 Battery Monitoring
• 🚨 Emergency Alert
• 📡 Wi-Fi Monitoring
• 💻 Web Dashboard

الواجهة تعرض Depth وTilt وBattery بشكل مباشر، وتظهر تنبيهًا عند الوصول إلى مستوى الخطر المحدد في الكود. ‎⁨التقرير النهائي للدعم والشبكات⁩.pdf

4. Hardware

ESP32 هو المتحكم الرئيسي، ويتم توصيل حساسات العمق والحركة به عبر I2C، مع Buzzer وحساس الطوارئ وقياس البطارية. ‎⁨التقرير النهائي للدعم والشبكات⁩.pdf

5. Future Improvements

• إضافة GPS لتحديد موقع الغواص.
• ربط النظام بتطبيق جوال.
• إضافة حساس نبض القلب والأكسجين.
• إرسال SOS تلقائي عند الخطر.
• تحسين مقاومة الماء والضغط.
• إضافة بطارية أقوى.
• استخدام الذكاء الاصطناعي للتنبؤ بالمخاطر. ‎⁨التقرير النهائي للدعم والشبكات⁩.pdf
